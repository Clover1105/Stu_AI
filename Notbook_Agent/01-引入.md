# 一、LangChain框架介绍

**LangChain 是一个用于开发 LLM（Large Language Model，大语言模型）应用程序的开发框架**

官方网址：<https://python.langchain.com/>

一句话概括**：LangChain = 大模型应用开发框架**

它帮助开发者快速构建【AI 聊天机器人、AI 智能助手、AI 办公助手、AI 数据分析、AI Agent、RAG 知识库、多智能体系统、企业 AI 应用】而不是仅仅调用一次大模型

LangChain 还提供了一套完整的大模型开发能力

```
                用户问题
                    │
                    ▼
              LangChain Agent
        ┌──────────┼──────────┐
        │          │          │
        ▼          ▼          ▼
      SQL      Knowledge      API
      Tool        Base        Tool
        │          │          │
        └──────────┼──────────┘
                    │
                    ▼
                  LLM
                    │
                    ▼
                 最终答案
```

它负责协调【大模型、工具、数据库、API、RAG、Workflow、Memory】让开发者只关注业务逻辑

**调用：**

```
from langchain.agents import create_agent
```

**LangChain 1.0 核心变化：**

1. **统一Agent开发入口**：将以往分散的 `initialize_agent`、`create_react_agent` 等 Agent 创建方式，统一为 `create_agent`，开发更简洁、标准化。
2. **企业级Middleware（中间件）**：支持在 Agent 执行流程（用户输入→LLM推理→工具调用等环节）中插入逻辑，实现**日志监控、权限控制**等企业级需求。
3. **内置Structured Output**：结构化输出直接集成到 Agent 循环中，无需额外调用 LLM 解析 JSON，实现**降成本、降延迟、更稳定**。
4. **智能Tool Calling**：Agent 可根据用户问题**自主决定是否调用工具**（而非强制调用），提升执行效率与决策智能性。

# 二、环境安装

python == 3.12

安装库

```
pip install "langchain[all]"==1.0.0 -i https://mirrors.aliyun.com/pypi/simple/
pip install python-dotenv -i https://mirrors.aliyun.com/pypi/simple/
pip install langchain-openai==1.0.0  -i https://mirrors.aliyun.com/pypi/simple/
pip install -U langchain-anthropic  -i https://mirrors.aliyun.com/pypi/simple/
```

或者直接安装老师发的`requirements.txt` 依赖管理文件

在文件所在目录下进入cmd，激活conda环境后，安装命令如下：

```
pip install -r requirements.txt
```
