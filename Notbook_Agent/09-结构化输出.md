# 一、为什么要结构化

## （一）原因

大模型（LLM）天生是一个“语言生成器”，它的默认输出是**人类可读的自然语言（文本）**。但在实际的软件开发和智能体（Agent）系统中，程序无法直接理解自然语言，必须依赖**结构化数据**。

## （二）目的

将智能体的输出强制转化为 JSON 格式，主要是为了解决以下几个核心痛点：

### 1. 方便程序解析与自动化流转

JSON 是一种高度标准化的数据交换格式。当大模型输出 JSON 后，你的 Python 代码可以通过 `json.loads()` 直接将其转换为字典（Dictionary）或对象。

- **如果不转 JSON**：程序需要去写复杂的正则表达式，从一堆废话（比如“好的，这是您的验证码...”）中抠出关键信息，极其脆弱。
- **转了 JSON**：程序可以直接通过 `data['code']` 或 `data['msg']` 精准提取数据，无缝对接后端的业务逻辑。

### 2. 作为智能体（Agent）的“决策指令”

在 LangChain 等框架中，智能体通常需要调用工具（Tools）。大模型在决定调用哪个工具、传什么参数时，往往就是通过输出 JSON 来实现的。

- 例如：`{"tool": "send_email", "args": {"to": "xxx@qq.com"}}`。
- 框架解析这段 JSON 后，就能自动触发对应的函数执行。如果没有结构化格式，智能体就无法实现“自主思考和行动”的闭环。

### 3. 便于数据校验（Data Validation）

结合你代码中使用的 `Pydantic`（如 `class code_format_schema`），JSON 格式可以与数据校验库完美配合。

- 它可以自动检查大模型是否漏传了字段、字段类型是否正确（比如 `code` 必须是字符串）。
- 如果大模型“幻觉”输出了不合规的数据，Pydantic 会直接报错拦截，防止脏数据流入系统。

### 4. 跨系统的标准化通信

在实际架构中，大模型通常只是整个系统的一个“大脑节点”。它输出的 JSON 可以直接作为 HTTP API 的响应体返回给前端，或者作为消息队列（如 Kafka、RabbitMQ）的数据包发送给下游微服务。JSON 是目前前后端和微服务之间最通用的“普通话”。

## （三）总结

大模型就像一个只会说自然语言的“文科生”，而你的后端系统是一个只认表格的“理科生”。**JSON 就是他们之间的“翻译官”**。强制大模型输出 JSON，就是强迫这位文科生在回答问题时，必须按照标准的表格格式填写，这样理科生才能直接拿去录入数据库。

# 二、Langchain 实现方式

## （一）LangChain 中智能体与结构化输出结合

LangChain 提供了强大的功能，可以结合大语言模型和工具来进行结构化输出。智能体可以通过结合工具和提示模板（PromptTemplate）来实现复杂的输出需求

### 1. 需求

输出格式要求如下：

```
# 发送成功
{'data': '8429', 'code': 200, 'msg': '邮件已经发送'}

# 发送失败
{'data': '', 'code': 500, 'msg': '失败原因说明'}
```

### 2. 类型校验

验证码格式校验：

```
class code_format_schema(BaseModel):
    data:str = Field(description="验证码")
    code:str = Field(description="状态码，200表示成功，500表示失败")
    msg:str = Field(description="提示信息")
```

### 3. 创建大模型

使用本地或在线大模型 -- `my_model.py`

```
from langchain_openai import ChatOpenAI
from dotenv import load_dotenv
import os
load_dotenv()

class MyModel:
    # 定义私有属性
    _model = None
    # 定义本地模型私有属性
    _local_model = None
    # 定义静态函数，在线模型
    @staticmethod   # 静态方法，不需要实例化对象就可以调用
    def get_model():
        # 判断_model是否为空
        if MyModel._model is None:
            # 为空，创建模型
            MyModel._model = ChatOpenAI(
                model=os.getenv("MODEL_ONLINE_NAME"),
                api_key=os.getenv("DASHSCOPE_API_KEY"),
                streaming=True,
            )
        return MyModel._model

    # 本地模型创建
    @staticmethod
    def get_local_model():
        # 判断_local_model是否为空，为空，创建模型
        if MyModel._local_model is None:
            MyModel._local_model = ChatOpenAI(
                model=os.getenv("MODEL_LOCAL_NAME"),
                api_key="22",
                base_url=os.getenv("LOCAL_URL"),
                streaming=True,
            )
        return MyModel._local_model

model = my_model.MyModel.get_local_model()
```

### 4. 创建工具

```
from langchain.tools import tool
from email.mime.text import MIMEText    # 写邮件
import smtplib  # 发送邮件
from tool.schema.send_email_schema import EmailParams
from dotenv import load_dotenv
import os
load_dotenv()


# 定义工具
@tool(
    "send_email_tool",  # 可选，默认用对应方法名作为工具名称
    description="发送邮件工具",
    args_schema=EmailParams,
)
def SendEmailTool(to:str,subject:str,content:str)->str:
    """
    用于发送邮件，发送通知，发送信息
    """
    # 每个工具都要加异常处理
    try:
        # 读取配置文件信息
        email = os.getenv("SENDER_EMAIL")   # 发件人邮箱
        host = os.getenv("EMAIL_HOST")
        port = os.getenv("EMAIL_PORT")
        password = os.getenv("SENDER_EMAIL_PASSWORD")
        # 判断配置是否读取成功
        if not email or not host or not port or not password:
            raise Exception("配置文件信息读取失败")
        # 创建邮件对象
        msg = MIMEText(content)
        msg['To'] = to  # 收件人
        msg['Subject'] = subject    # 邮件主题
        msg['From'] = email  # 发件人
        # 创建一个链接邮件服务器地址
        with smtplib.SMTP_SSL(host,int(port)) as smtp:  # port读取出来为字符串，需要转换为int
            # 登录邮件服务器
            smtp.login(email,password)
            # 发送邮件
            smtp.sendmail(email,to,msg.as_string())
        return "发送邮件成功\n"
    except Exception as e:
        print(f"发送邮件失败:{e}")
        return f"发送邮件失败:{e}"

tools = [SendEmailTool]
```

### 5. 定义提示词

```
prompt = """

        - 如果邮件发送失败，状态码是500，提示信息是"邮件发送失败"
    -- 输出：
        - 输出内容是：验证码、状态码、提示信息
    -- 示例
        - 输入：邮箱是123456@qq.com,发送邮件
        - 输出：验证码，状态码，提示信息
"""
```

```
agent = create_agent(
```
