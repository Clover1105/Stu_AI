# 一、智能体

Agent（智能体）是一种能够**自主思考（Reasoning）**、**自主调用工具（Tool Calling）**、**根据工具结果继续决策（Observation）**，最终完成复杂任务的大模型工作模式

```
用户
   │
   ▼
LLM
   │
   ▼
判断是否需要工具
   │
 ┌─┴────────────┐
 │              │
 ▼              ▼
Tool1         Tool2
 │              │
 └──────┬───────┘
        ▼
 Observation
        ▼
 继续思考(Reasoning)
        ▼
 Final Answer
```

> Agent = LLM + Thinking + Tool + Workflow

# 二、智能体创建

步骤：定义工具、初始化大语言模型、定义提示词、创建智能体、运行智能体

## （一）定义工具

工具是智能体的“手脚”。Lang Chain 1.0 依然推荐使用 `@tool` 装饰器来定义工具，函数的**文档字符串**至关重要，因为它会作为工具的描述被传递给模型，帮助模型判断何时调用该工具

创建一个发送邮件的工具，代码如下（`SendEmailTool.py`）：

```python
from langchain.tools import tool
from pydantic import BaseModel,Field
from email.mime.text import MIMEText    # 写邮件
import smtplib  # 发送邮件
from dotenv import load_dotenv
import os
load_dotenv()

# 定义工具参数校验类
class EmailParams(BaseModel):
    # 收件人
    to:str = Field(...,description="收件人邮箱")
    # 邮件主题
    subject:str = Field(...,description="邮件主题")
    # 邮件内容
    content:str = Field(...,description="邮件内容")

# 定义工具
@tool(
    "send_email_tool",  # 可选，默认用对应方法名作为工具名称
    description="发送邮件工具",
    args_schema=EmailParams,
)
def send_email_tool(to:str,subject:str,content:str)->str:
    """
    用于发送邮件，发送通知，发送信息
    """
    # 每个工具都要加异常处理
    try:
        # 读取配置文件信息
        email = os.getenv("SENDER_EMAIL")   # 发件人邮箱
        host = os.getenv("EMAIL_HOST")
        port = os.getenv("EMAIL_PORT")
        password = os.getenv("SENDER_EMAIL_PASSWORD")
        # 判断配置是否读取成功
        if not email or not host or not port or not password:
            raise Exception("配置文件信息读取失败")
        # 创建邮件对象
        msg = MIMEText(content)
        msg['To'] = to  # 收件人
        msg['Subject'] = subject    # 邮件主题
        msg['From'] = email  # 发件人
        # 创建一个链接邮件服务器地址
        with smtplib.SMTP_SSL(host,int(port)) as smtp:  # port读取出来为字符串，需要转换为int
            # 登录邮件服务器
            smtp.login(email,password)
            # 发送邮件
            smtp.sendmail(email,to,msg.as_string())
        return "发送邮件成功\n"
    except Exception as e:
        print(f"发送邮件失败:{e}")
        return f"发送邮件失败:{e}"

if __name__ == '__main__':
    send_email_tool.invoke({
        "to":"2920242909@qq.com",
        "subject":"测试邮件",
        "content":"测试邮件内容"
    })
```

智能体中调用：

```
from tool.SendEmailTool import send_email_tool
tools = [send_email_tool]
```

## （二）初始化语言大模型

语言模型是智能体的“大脑”。你可以直接初始化一个模型实例，并进行参数配置（如温度、最大 token 数等）。Lang Chain 1.0 的模型集成更加模块化。

创建了一个在线模型和一个本地模型，目前调用在线模型，代码如下（`MyModel.py`）：

```python
from langchain_openai import ChatOpenAI
from dotenv import load_dotenv
import os
load_dotenv()

"""
基于单例模式的模型封装
"""

class MyModel:
    # 定义私有属性
    _model = None
    # 定义本地模型私有属性
    _local_model = None
    # 定义静态函数，在线模型
    @staticmethod   # 静态方法，不需要实例化对象就可以调用
    def get_model():
        # 判断_model是否为空
        if MyModel._model is None:
            # 为空，创建模型
            MyModel._model = ChatOpenAI(
                model=os.getenv("MODEL_ONLINE_NAME"),
                api_key=os.getenv("DASHSCOPE_API_KEY"),
                streaming=True,
            )
        return MyModel._model

    # 本地模型创建
    @staticmethod
    def get_local_model():
        # 判断_local_model是否为空，为空，创建模型
        if MyModel._local_model is None:
            MyModel._local_model = ChatOpenAI(
                model=os.getenv("MODEL_LOCAL_NAME"),
                api_key="22",
                base_url=os.getenv("LOCAL_URL"),
                streaming=True,
            )
        return MyModel._local_model

if __name__ == '__main__':
    model = MyModel.get_model()
    # model = MyModel.get_local_model()
    rs = model.invoke("你好")
    print(rs)
```

智能体中调用：

```python
from model import MyModel
model = MyModel.MyModel.get_model()
```

## （三）定义提示词

提示词主要定义智能体的行为准则（角色、边界、流程）。提示词越清晰，模型决策越稳定。

```python
prompt = """
        -- 角色：你是一个专业的邮件发送助手
    """
```

## （四）创建智能体

把前面准备好的模型、工具和系统提示词组装成可执行的智能体

```python
from langchain.agents import create_agent

agent = create_agent(
        model, tools,
        system_prompt=prompt,
        debug=True  # 可选，一般用于调试，生成环境必须设置为false
    )
```

## （五）运行智能体

创建好的智能体可以通过 `invoke` /`stream`方法来执行任务

输入格式是包含 `messages` 的字典，通常以 `{"role": "user", "content": "你的问题"}` 的形式传入

```python
from langchain_core.messages import HumanMessage

human_msg = {"messages":[HumanMessage(content=que)]}
result = agent.invoke(human_msg)    # 非流式输出
print(result)
```

# 三、智能体工作原理

一个标准 Agent 的执行流程如下：

```
              用户问题
                  │
                  ▼
          LLM理解用户意图
                  │
                  ▼
         判断是否需要调用Tool
          │            │
          │否          │是
          │            ▼
          │      Tool Calling
          │            │
          │            ▼
          │     Tool执行完成
          │            │
          │            ▼
          │     Observation
          │            │
          │            ▼
          │      Reasoning
          │            │
          └────────────┤
                       ▼
                  Final Answer
```

整个流程通常会循环执行多轮，因此 Agent 并不是一次完成，而是【思考 → 调工具 → 再思考 → 再调工具 → 输出答案】

## （一）Tool Calling

Tool Calling ：工具调用，大模型决定调用哪个工具，并生成工具参数。

整个过程都是 LLM 自动完成：

```
用户问题
      │
      ▼
LLM分析问题
      │
      ▼
需要发送邮件
      │
      ▼
生成邮件工具参数
      │
      ▼
调用Tool
      │
      ▼
得到Tool结果
```

## （二）Observation（观察）

Agent 获取 Tool 返回结果后的"观察阶段"

工具执行后返回的结果，这个返回结果，就是 **Observation（观察）**

## （三）Reasoning（推理）

Reasoning 是 Agent 最重要的能力，根据 Observation，继续思考下一步应该做什么

智能体接收到问题后，并不会立刻调用邮件工具，而是先进行推理（Reasoning）

Reasoning 就是 Agent 的"思考过程"，负责分析用户需求、决定下一步行动，并根据工具返回的结果继续思考，直到任务完成
