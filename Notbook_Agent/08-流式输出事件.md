# 一、流式输出

在 LangChain 中，流式输出（Streaming Output）是一个非常强大的特性，能够让用户实时接收到模型的输出结果，而不是等待整个任务完成后才返回结果。LangChain 提供了几个流式输出接口，常见的有以下几种：

| 方法                 | 是否流式 | 返回内容           |
| -------------------- | -------- | ------------------ |
| stream()             | √        | 最终回复流         |
| astream()            | √        | 最终回复流（异步） |
| **astream_events()** | √        | **整个执行过程**   |

# 二、astream_events

astream() 和 astream_events() 最大的区别就是：

- **astream() 只能看到模型回答。**

- **astream_events() 可以看到 Agent 的全部执行生命周期**

## （一）基本语法

```
async for event in agent.astream_events(
    {"messages":[HumanMessage(content="查询张三邮箱")]},
    version="v2"
):
    print(event)
```

官方推荐优先使用 `version="v2"`，它支持更完整的事件信息（包括父子运行关系及自定义事件）

**返回的数据结构**：

每一个 event 都是一个字典

```
{
    "event":"on_tool_start",
    "name":"mysql_tool",
    "run_id":"xxxxx",
    "parent_ids":[...],
    "metadata":{},
    "tags":[],
    "data":{}
}
```

| 字段       | 说明                |
| ---------- | ------------------- |
| event      | 当前事件            |
| name       | Runnable名称        |
| run_id     | 当前运行ID          |
| parent_ids | 父任务ID（v2 支持） |
| metadata   | 元数据              |
| tags       | 标签                |
| data       | 实际数据            |

## （二）企业开发最常监听的事件

在实际项目中，通常只监听下面几个事件即可：

| 事件                   | 用途                                       |
| ---------------------- | ------------------------------------------ |
| `on_chat_model_stream` | 实现 ChatGPT 打字机效果（SSE/WebSocket）   |
| `on_tool_start`        | 提示"正在查询数据库..."、"正在联网搜索..." |
| `on_tool_end`          | 提示工具执行完成                           |
| `on_tool_error`        | Tool 异常处理                              |
| `on_chain_start`       | 整个 Agent 开始执行                        |
| `on_chain_end`         | Agent 执行结束                             |

## （三）测试代码

```python
import asyncio

from langchain_core.messages import HumanMessage

from model import MyModel
from langchain.agents import create_agent

from tool.SendEmailTool import send_email_tool
from tool.add_toll import AddToll

"""创建智能体步骤"""
async def create_email_agent(que):
    # 1. 创建一个大模型
    model = MyModel.MyModel.get_model()
    # 2. 创建一个工具
    tools = [send_email_tool,AddToll]
    # 3. 创建提示词 -- 系统提示词
    prompt = """
        -- 角色：你是一个专业的邮件发送助手
        -- 约束：
            1. 当用户要求发送邮件时，只调用一次 send_email_tool。
            2. 工具返回成功后，直接告诉用户发送完成，不要再次调用工具。
            3. 严禁重复执行相同的操作。
    """
    # 4. 创建智能体
    agent = create_agent(
        model, tools,
        system_prompt=prompt,
        # debug=True  # 可选，一般用于调试，生成环境必须设置为false
    )
    # 5. 提问
    human_msg = {"messages":[HumanMessage(content=que)]}
    # 6. 回答
    async for event in agent.astream_events(human_msg,version="v2"):
        print(event)
        # 获取事件内容
        event_name = event['event'] # 事件名称
        if event_name == 'on_chain_start':
            yield f"邮件智能体开始运行。。。\n\n"
        elif event_name == 'on_chain_end':
            yield f"邮件智能体停止运行！！！\n\n"
        elif event_name == 'on_chat_model_start':
            yield f"大模型开始思考。。。\n\n"
        elif event_name == 'on_chat_model_end':
            yield f"大模型思考结束！！！\n\n"
        elif event_name == 'on_chain_stream':
            yield f"大模型开始生成答案。。。\n\n"
        elif event_name == 'on_tool_start':
            # 获取工具名称
            tool_name = event['name']
            if tool_name == "send_email_tool":
                yield f"开始发送邮件。。。\n\n"
        elif event_name == 'on_tool_end':
            # 获取工具返回值
            tool_output = event['data']['output'].content
            yield f"邮件工具执行完毕，执行结果为{tool_output}\n\n"
        elif event_name == 'on_chat_model_stream':
            data = event['data']['chunk'].content
            if data:
                yield data

# 创建一个迭代器
async def test(que):
    async for rs in create_email_agent(que):
        print(rs,end="")

if __name__ == '__main__':
    que = "请发送一封邮件给2920242909@qq.com，内容为一段心灵鸡汤"
    asyncio.run(test(que))
```
