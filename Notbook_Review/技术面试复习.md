# 一、langchain和langgraph的区别

2个框架都是用于做智能体等业务开发的

langchain是基于langgraph上封装的应用层框架

langgraph是一个更底层的框架

create_agent是langchain提供的一个创建智能体的api，底层其实就是langgraph编排的一个内置图

# 二、工作流和智能体的区别

dify搭建出来的内容：工作流

智能体和工作流的区别在于：工作流可以看作是一个特殊的 agent，即流程固定

# 三、MCP和Skills

MCP：模型上下文协议，可以把工具抽取出来定义在 MCP服务器中，然后以统一的接口的形式暴露出来提供给其他业务调用

MCP 框架：FastMCP

Skills：它可以把固定流程的提示词、代码等抽取出来，定义成为一个 skill，当你的业务需要使用到哪一个 skill的时候，才会去动态加载
