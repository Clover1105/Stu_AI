# 一、prompt

Prompt（提示词）就是**告诉大模型应该如何工作的指令**，**控制 AI 行为的一种方式**

**作用：**限制大模型的任务、通过提示词让用户知道这个智能体是干嘛的

简单来说：Prompt = 给 AI 下达工作任务。

# 二、组成

```
┌───────────────────────┐
│      System Prompt     │
└──────────┬────────────┘
           │
┌──────────▼────────────┐
│      Human Prompt      │
└──────────┬────────────┘
           │
┌──────────▼────────────┐
│      AI Response       │
└────────────────────────┘
```

**System Prompt**：系统提示词、工具提示词、记忆，【用于规定 AI 的身份、能力、规则】

**Human Prompt**：用户的问题，用户的输入

**AI Response**： AI的回答、历史回答（上下文）

# 三、企业级编写规范

在企业级 AI Agent 开发中，**使用 YAML 格式编写提示词（Prompt as Configuration）非常重要**。它把 Prompt 从代码中分离出来，形成一种**可维护、可管理、可版本控制的智能体配置文件**

- Prompt 与代码解耦（最重要） -- 解耦：降低依赖性
- 方便多个智能体统一管理，因为企业通常有很多 Agent
- 支持企业 Prompt 版本管理，企业会使用 Git 管理
- 统一 Prompt 标准，因为企业不希望每个人随便写 Prompt，所以会通过 YAML 固定结构形成企业 Prompt 规范
- 方便业务人员可以修改

| 格式       | 扩展名           | 优点                        | 缺点                   | 企业使用频率 |
| ---------- | ---------------- | --------------------------- | ---------------------- | ------------ |
| `JSON`     | `.json`          | 结构化强，支持多语言/多版本 | 不能写注释，尾逗号严格 | ⭐⭐⭐⭐         |
| `YAML`     | `.yaml` / `.yml` | 可读性最好，支持注释        | 缩进敏感，容易出错     | ⭐⭐⭐⭐         |
| `Markdown` | `.md`            | 天然适合长文本，可读性高    | 结构化能力弱           | ⭐⭐⭐          |
| `TXT`      | `.txt`           | 最简单，通用                | 无结构，管理混乱       | ⭐⭐           |

## （一）结构化

一个高质量的 Prompt 通常应包含以下几个部分：

- 角色（Role）
- 任务（Task）
- 规则（Rules）
- 输出格式（Output）
- 示例（example）

这种结构化 Prompt 更容易维护，也更容易获得稳定、高质量的模型输出

```
prompt = """
        1. 角色：你是一个专业的邮件发送助手
        2. 任务：
            （1）根据用户输入问题发送邮件
        3. 规则：
            （1）你只能根据用户输入问题发送邮件
            （2）如果不是发送邮件的问题，告知用户，只能发送邮件
            （3）如果邮件内容为空，告知用户，邮件为空
            （4）如果邮箱格式不正确，告知用户，邮箱格式不正确
        4. 输出：
            （1）只输出json格式，不能输出其他格式
            （2）json格式如下：{"output":"xxx"}
        5. 示例：
            输入：请解释一下python是什么
            输出：只能发送邮件
            输入：请发送一封邮件给2920242909@qq.com
            输出：邮件内容为空
    """
```

## （二）定义提示词

创建一个 `send_email_agent.yaml` 文件，文件内容如下：

```yaml
role: 你是一个邮件发送助手
task:
  - 理解用户需求
  - 根据用户输入问题，发送邮件
rule:
  - 你只能根据用户输入问题发送邮件
  - 如果不是发送邮件的问题，告知用户，只能发送邮件
  - 如果邮件内容为空，告知用户，邮件为空
  - 如果邮箱格式不正确，告知用户，邮箱格式不正确
output:
  - 只输出json格式，不能输出其他格式
  - json格式如下：{"output":"xxx"}
example:
  - 输入：请解释一下python是什么
  - 输出：只能发送邮件
  - 输入：请发送一封邮件给2920242909@qq.com
  - 输出：邮件内容为空
```

- 文件内内容格式为：`key: value` —— 键值对
- 冒号 `:` 的作用：左边是字段名，右边是字段值
- 换行表示结束，空行没有特殊意义
- 短横杠 `-` 表示：列表（数组），`goal:` 表示定义一个字段，`-xxx` 表示列表元素
- 缩进代表层级关系，YAML 非常依赖缩进，使用两个空格缩进

## （三）定义提示词构建器（通用）

yaml 文件格式必须统一格式，这样只需要将文件名传入构建器就可以了

```python
import os
import yaml

class BuilderPromptYaml:
    _prompt = None

    # 定义静态函数
    @staticmethod
    def get_prompt(file_name):
        # 获取yaml文件所在目录
        dirname = os.path.dirname(os.path.abspath(__file__))
        # 拼接yaml文件路径
        file_path = os.path.join(dirname, file_name)
        # 读取yaml文件，转为python数据类型
        with open(file_path, 'r', encoding='utf-8') as f:
            config = yaml.safe_load(f)
        print(config)
        print(type(config)) # <class 'dict'>

        # 字符串拼接 -- 构建提示词
        BuilderPromptYaml._prompt = f"""
        1. 角色：{config['role']}\n2. 任务：{"\n".join(config['task'])}\n3. 规则：{"\n".join(config['rule'])}\n4. 输出：{"\n".join(config['output'])}\n5. 示例：{"\n".join(config['example'])}\n
        """
        return BuilderPromptYaml._prompt.strip()


"""
os.path.abspath(__file__) -- 获取当前文件的绝对路径
os.path.dirname(os.path.abspath(__file__)) -- 获取当前文件的父目录
"""
if __name__ == '__main__':
    rs = BuilderPromptYaml.get_prompt("send_email_agent.yaml")
    print(rs)
```

智能体中调用：

```python
from prompt.builder_prompt_yaml import BuilderPromptYaml
prompt = BuilderPromptYaml.get_prompt("send_email_agent.yaml")
```

# 四、核心

- **Prompt 是控制大模型行为的核心手段。**
- **System** 用于定义模型身份、规则和输出风格。
- **Human** 表示用户输入，**AIMessage** 保存模型历史回复，共同构成对话上下文。
- **Messages** 是聊天模型真正接收的数据结构。
- 编写 Prompt 时，应遵循 **角色 → 任务  → 规则 → 输出格式** 的结构化设计思想，以提高模型输出的稳定性和可维护性。
