# 一、项目介绍

## （一）概述

### 1. 项目定位

这是一个面向企业招聘场景的 **Agentic AI（代理智能）模拟面试平台**。

基于 **LLM + LangChain + LangGraph** 构建

### 2. 核心设计理念

采用“**确定性逻辑程序化、非确定性任务智能化**”的混合架构。

- *确定性逻辑*：如面试流程流转（出题->答题->评价）、状态管理，通过代码硬控制保证稳定性。
- *非确定性任务*：如题目生成、答案分析、意图理解，交给大模型（LLM）处理以保证灵活性。

### 3. 关键技术组合

- **编排层**：使用 `LangGraph` 构建有状态的多智能体工作流。这是项目的核心骨架，解决了传统 Chain 无法处理循环和复杂状态跳转的问题。将用户意图识别、面试题管理、答题交互、答案分析及综合评价进行模块化编排。
- **状态管理**：==利用 `ExamState`（自定义状态类）+ `Thread ID` + `Checkpoint` 机制==。这意味着系统支持**断点续传**和**多轮对话记忆**，每次交互都能基于之前的上下文（Context）进行，而不是无状态的问答。
- **实时性**：集成 `FastAPI` + `SSE` (Server-Sent Events) + `MySQL` + `Redis`。支持多轮面试会话，为了让用户感觉像是在和真人对话，AI 的回答不是等生成完才显示，而是像打字机一样流式输出（Stream）。
- **传输链路**：通过`astream`、`get_stream_writer` 和 `custom stream` 打通了从 Agent 内部模型输出 -> 后端 Stream Writer -> 前端 SSE 接收的全链路实时传输。

## （二）核心业务流程

**流程协同机制**：整个面试不是由一个巨大的 Prompt 完成的，而是拆解为 **5个专职智能体节点** 协同工作。这种模块化设计便于后续单独优化某个环节（比如只优化出题质量，不影响评价逻辑）。

| 节点                       | 职责                                       |
| -------------------------- | ------------------------------------------ |
| **Manager（主管节点）**    | 调度中枢，根据考试状态决定下一个执行的节点 |
| **Intent（意图识别节点）** | 解析用户输入，提取课程类型和题目数量       |
| **Question（出题节点）**   | 从题库中查询并返回一道随机题目             |
| **Answer（答题节点）**     | 收集用户答案，判断是否继续出题或进入评价   |
| **Evaluation（评价节点）** | 对所有题目的作答进行综合评分，生成评价报告 |

## （三）系统架构

系统整体架构分为三层：

- **前端层**：Vue.js 单页应用，包含登录页和聊天页，通过 SSE 和 WebSocket 与后端通信
- **服务层**：FastAPI 应用，注册多个路由模块，通过 LangGraph 编排多智能体工作流
- **数据层**：MySQL 存储题库和用户信息，Redis 存储验证码，Vosk 本地语音模型

```
┌─────────────────────────────────────────────┐
│                  前端层                      │
│   login.html (登录)    chat.html (聊天)      │
│       ↕ HTTP/SSE            ↕ WebSocket     │
├─────────────────────────────────────────────┤

│  ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│  │ system   │ │  chat    │ │ websocket│     │
│  │ _router  │ │ _router  │ │ _router  │     │
│  └──────────┘ └────┬─────┘ └──────────┘     │
│                    │                        │
│         ┌──────────▼──────────┐             │
│         │   LangGraph 多智能体  │            │
│         │  Manager → Intent   │             │
│         │  → Question → Answer │            │
```

# 三、服务器

## （一）启动程序 -- `main.py`

整个后端服务的**总入口**。

主要职责是：初始化 FastAPI 应用、挂载静态资源（前端页面）、注册所有业务路由，以及管理全局资源（如 AI 智能体）的生命周期。

### 1. 基础启动

- 创建 FastAPI 实例 `app`。这是所有 Web 请求的载体。
- `uvicorn.run(...)` 是 ASGI 服务器的启动命令。这里硬编码了 `localhost` 和 `8000` 端口。
- 后续所有的路由注册（Router）和生命周期管理（Lifespan）都是基于这个 `app` 对象进行的。

```python
from fastapi import FastAPI
import uvicorn

app = FastAPI()

if __name__ == '__main__':
    uvicorn.run(app, host='localhost', port=8000)
```

### 2. 静态资源访问目录

- 将项目根目录下的 `./html` 文件夹映射为网络路径 `/static`。
- 这意味着前端页面（如 `chat.html`）可以直接通过浏览器访问 `http://localhost:8000/static/chat.html`。
- 这实现了前后端的一体化部署。不需要单独起一个 Nginx 来托管 HTML 文件，FastAPI 直接充当了静态文件服务器，方便开发调试。

```python
from fastapi.staticfiles import StaticFiles

app.mount("/static",StaticFiles(directory="./html"),name="static")
```

### 3. 注册路由

采用 FastAPI 的 `APIRouter` 子路由模式，将不同功能模块拆分为独立的路由文件，避免 `main.py` 过于臃肿。

| 路由模块              | 路由前缀              | 职责                              |
| --------------------- | --------------------- | --------------------------------- |
| `default_page_router` | `/`                   | 根路由，重定向到登录页面          |
| `system_router`       | `/sendCode`、`/login` | 验证码发送和登录验证              |
| `chat_router`         | `/chat`、`/vosk`      | SSE 流式聊天 + 语音识别 WebSocket |
| `websocket_router`    | `/test`               | WebSocket 通信测试                |

- `include_router` 将分散在各个文件中的接口“拼装”到主应用 `app` 上。
- **`chat_router`**：核心业务接口，处理面试对话流（SSE）和语音流（WebSocket）。
- **`ws_router`**：测试专用，用于验证 WebSocket 连接是否正常。
- 这里是请求分发的枢纽。当用户在前端点击“发送”时，请求会先到达这里，然后根据路径被分发到具体的 `chat_router` 中去处理业务逻辑。

```python
from app.web.chat_router.chat_router import chat_router
from app.web.websocker_router.websocket_test import ws_router
from app.web.default_page_router.default_page_router import default_page_router

app.include_router(chat_router)
app.include_router(ws_router)
app.include_router(default_page_router)
```

### 4. 生命周期

用于管理 **AI 智能体（ExamGraph）** 的初始化

- **单例模式实现**：利用 `lifespan` 机制，确保 `ExamGraph`（包含复杂的 LangGraph 图和模型加载）**只在服务器启动时加载一次**，而不是每次用户请求都重新加载。这极大地提高了响应速度并节省了显存/内存。
- **状态共享**：通过 `app.state.exam_agent` 将初始化好的智能体对象暴露给全局。
- **InMemorySaver**： LangGraph 的记忆组件。这里使用的是内存存储，意味着**重启服务器后，所有的面试历史记录都会丢失**。
- 它向上支撑了 `chat_router` 中的业务逻辑。当 `chat_router` 需要调用 AI 进行面试时，它直接从 `app.state` 取出这个已经准备好的 `exam_agent` 使用。

```python
from contextlib import asynccontextmanager
from app.ai.agent.multi_agent.graph.exam_graph import ExamGraph
from langgraph.checkpoint.memory import InMemorySaver

# 定义异步上下文管理器
@asynccontextmanager
async def content_manager(app:FastAPI):
    # --- 启动阶段 (Startup) ---
    
    # 创建内存级检查点存储器，用于 LangGraph 保存对话历史状态
    memory = InMemorySaver()
    
    # 初始化 ExamGraph（面试大脑），并将 memory 传入
    # 存入 app.state 以便在路由文件中通过 request.app.state.exam_agent 全局调用
    app.state.exam_agent = ExamGraph(memory)
    print("【测试】AI模拟面试智能体创建成功")
    
    # yield 之前的代码在服务器启动时执行
    yield
    
    # --- 关闭阶段 (Shutdown) ---
    
    # 消耗对象
    # yield 之后的代码在服务器关闭时执行
    app.state.exam_agent = None
    print("【测试】AI模拟面试智能体消耗成功")

app = FastAPI(lifespan=content_manager)
```

## （二）默认启动页面配置 -- `default_page_router.py`

主要作用：是作为网站的“门卫”，处理根路径的访问请求，将用户引导至正确的业务页面。

- **定义路由组**：创建了一个名为 `default_page_router` 的路由器实例。在 `main.py` 中，它被挂载到了根路径 `/` 下。
- **根路径重定向**：当用户直接访问 `http://localhost:8000/` 时，触发 `default_page` 函数。
- 它不直接返回 HTML 内容，而是使用 `RedirectResponse` 将请求重定向到 `/static/chat.html`。这与 `main.py` 中挂载的静态资源目录（`./html` 映射为 `/static`）形成了闭环，确保用户一打开网站就能看到聊天/面试界面。

```python
from fastapi import APIRouter
from fastapi.responses import RedirectResponse

default_page_router = APIRouter()

@default_page_router.get("/")
async def default_page():
    return RedirectResponse(url="/static/chat.html")
```

## （三）模型 -- `my_model.py`

这是项目的**AI 基础设施层**。为了统一管理不同来源的模型（本地部署的、云端的、语音识别的），代码使用了 `MyModel` 类进行封装，并采用了**单例模式（Singleton Pattern）**的设计思想（通过静态变量判断是否为空），避免重复加载模型导致内存溢出或初始化开销过大。

### 1. 导入

- `ChatOpenAI`：LangChain 提供的通用接口。**注意**：虽然名字叫 OpenAI，但它兼容所有支持 OpenAI 格式的 API（包括本地部署的 Ollama/vLLM 和阿里云 DashScope），这是实现“本地/在线”切换的关键。
- `load_dotenv()`：加载 `.env` 文件中的环境变量（如 API Key、模型路径），避免敏感信息硬编码在代码中。
- `vosk.Model`：用于加载离线的语音识别模型。

```python
from langchain_openai import ChatOpenAI
from dotenv import load_dotenv
from vosk import Model
import os

load_dotenv()
```

### 2. 本地

- **单例获取**：通过 `get_local_model` 静态方法获取模型实例。如果是第一次调用，则初始化；后续调用直接返回缓存对象。
- **配置来源**：模型名称 (`MODEL_LOCAL_NAME`) 和地址 (`LOCAL_URL`) 均从环境变量读取，方便切换不同的本地模型（如 Qwen2.5-7B 或 72B）。
- **流式输出**：`streaming=True` 是关键配置，配合前端的 SSE 技术，实现打字机效果。
- **思考模式**：`extra_body` 传递了自定义参数 `enable_thinking`，这通常是某些特定推理模型（如 DeepSeek-R1 类）特有的参数，用于控制是否输出思维链过程。

```python
class MyModel:
    # 定义本地模型私有属性
    _local_model = None
    # 本地模型创建
    @staticmethod
    def get_local_model():
        # 判断_local_model是否为空，为空，创建模型
        if MyModel._local_model is None:
            MyModel._local_model = ChatOpenAI(
                model=os.getenv("MODEL_LOCAL_NAME"),
                api_key="22",
                base_url=os.getenv("LOCAL_URL"),
                streaming=True,
                # 是否开启思考模式
                extra_body={
                    "enable_thinking": False
                }
            )
        return MyModel._local_model
```

### 3. 在线

- **云端接入**：逻辑与本地模型几乎一致，区别在于 `api_key` 读取的是 `DASHSCOPE_API_KEY`（阿里云通义千问的密钥）。
- 在后续的 `exam_graph.py` 或各个 Node 中，会根据业务需求（比如是需要高智商回答还是快速响应）来决定调用 `get_model()` 还是 `get_local_model()`。目前看代码结构，两者参数高度一致，便于无缝切换。

```python
class MyModel:
    # 定义私有属性
    _model = None
    # 定义静态函数，在线模型
    @staticmethod   # 静态方法，不需要实例化对象就可以调用
    def get_model():
        # 判断_model是否为空
        if MyModel._model is None:
            # 为空，创建模型
            MyModel._model = ChatOpenAI(
                model=os.getenv("MODEL_ONLINE_NAME"),
                api_key=os.getenv("DASHSCOPE_API_KEY"),
                streaming=True,
                # 是否开启思考模式
                extra_body={
                    "enable_thinking": False
                }
            )
        return MyModel._model
```

### 4. 语音

- **离线识别核心**：这里加载的是 Vosk 的声学模型文件。Vosk 是一个完全离线的语音识别工具包，不需要联网即可将用户的语音转为文字。
- **资源密集型**：Vosk 模型加载通常比较慢且占用内存，所以这里必须使用单例模式（`if ... is None`），确保整个服务运行期间只加载一次。
- 这个模型对象会被传递给 `vosk_agent.py`（语音智能体），用于处理 WebSocket 传来的音频流数据。

```python
class MyModel:
    # 定义语音模型
    _vosk_model = None
    # 加载语音模型
    @staticmethod
    def get_vosk_model():
        # 判断 _vosk_model 是否为空，为空，创建模型
        if MyModel._vosk_model is None:
            # 创建模型
            model_path = os.getenv("VOSK_MODEL_PATH")
            print(f'【测试】模型路径：{model_path}')
            # 加载模型
            MyModel._vosk_model = Model(model_path=model_path)
            print('【测试】模型加载完成')
        return MyModel._vosk_model
```

## （四）连接数据库 -- `mysql_conn.py`

作用：数据库操作的底层驱动，负责建立与 MySQL 的物理连接。

### 1. 导入

- `pymysql`：Python 连接 MySQL 的标准库。
- `dotenv`：用于加载 `.env` 文件中的环境变量。**这是为了安全**，避免将数据库密码直接硬编码在 Python 文件中。

```python
import pymysql
import os
from dotenv import load_dotenv

load_dotenv()
```

### 2. 获取连接

- **配置读取**：从环境变量中读取所有连接参数，实现了配置与代码分离。
- **DictCursor**：这是一个非常重要的细节。默认情况下 `pymysql` 返回的是元组（Tuple），如 `('value1', 'value2')`。设置 `cursorclass=pymysql.cursors.DictCursor` 后，返回结果会变成字典列表（List[Dict]），如 `[{'col1': 'value1', 'col2': 'value2'}]`。这对 LLM 理解数据结构非常友好。

```python
def GetMySQLConn():
    try:
        host = os.getenv("MYSQL_HOST")
        port = int(os.getenv("MYSQL_PORT"))
        user = os.getenv("MYSQL_USER")
        password = os.getenv("MYSQL_PASSWORD")
        database = os.getenv("MYSQL_DATABASE")
        charset = os.getenv("MYSQL_CHARSET")
        return pymysql.connect(
            host=host,
            port=port,
            user=user,
            password=password,
            database=database,
            charset=charset,
            # # 以 dict 的方式返回查询结果 -- [{a:b,x:y}]
            cursorclass=pymysql.cursors.DictCursor
        )
    except Exception as e:
        print(f"获取数据库连接失败：{e}")
        return None
```

### 3. 关闭连接

- **功能说明**：封装了标准的关闭流程，确保游标和连接都被正确释放，防止内存泄漏。

```python
def CloseMySQLConn(cursor,conn):
    cursor.close()
    conn.close()
```

## （五）数据库

将普通的数据库操作升级为了 **LangChain Tool（工具）**，使其能够被智能体（Agent）调用。

### 1. 参数校验 --  `mysql_schema.py`

- 定义了 Agent 调用工具时必须遵循的参数格式。
- LangChain 会根据这个 Schema 告诉 LLM：“如果你要查数据库，请给我一个名为 `sql` 的字符串参数”。这有助于提高 LLM 生成参数的准确率。

```python
from pydantic import BaseModel,Field

class MysqlSchema(BaseModel):
    sql: str = Field(...,description="sql语句")
```

### 2. 生成查询语句工具 -- `mysql_tool.py`

- **@tool 装饰器**：这是 LangChain 的核心机制。它将普通函数注册为工具，LLM 在推理过程中如果决定需要查库，就会生成调用这个函数的指令。
- **Docstring (文档字符串)**：函数下方的 `""" ... """` 内容非常重要。LLM 会读取这段文字来了解数据库的表结构（表名、字段）。**如果这里不写清楚表结构，LLM 生成的 SQL 语句大概率是错的。**
- **安全拦截（Security Guardrails）**：代码中间有一大段 `if "DELETE" ...` 的判断。这是为了防止 LLM “幻觉”或恶意操作导致删库。它强制限制了该工具只能执行 SELECT 查询。
- 这个工具通常会被传递给 `Manager` 节点或者专门的 `DatabaseAgent`，当用户问“你们有哪些职位？”时，Agent 就会调用此工具去 MySQL 里查数据。

```python
from  langchain.tools import tool
from app.ai.util.mysql_conn import GetMySQLConn
from app.ai.tool.schema.mysql_schema import MysqlSchema


@tool(
    description="接收mysql查询语句，并执行查询语句",
    args_schema=MysqlSchema
)
def mysql_tool(sql:str):
    """
    执行 sql 语句查询
    数据库模型：
        表名：xxx
        字段：xxx、xxxx、xxxx
        禁止生成DELETE、UPDATE、INSERT语句
    """
    print("\n【测试】这里是 -- mysql_tool.py")
    print(f"【测试】接收到的sql语句：{sql}")
    conn = None
    cur = None
    if "DELETE" in sql.upper() or "UPDATE" in sql.upper() or "INSERT" in sql.upper() or "DROP" in sql.upper() or "CREATE" in sql.upper() or "ALTER" in sql.upper():
        return "禁止执行非法sql语句操作"
    try:
        conn = GetMySQLConn()
        cur = conn.cursor()
        cur.execute(sql)
        result = cur.fetchall()
        return result
    except Exception as e:
        print(f"【测试】执行sql语句失败：{e}")
        return "执行sql语句失败"
    finally:
        if cur:
            cur.close()
        if conn:
            conn.close()
```

### 1. 参数校验 -- `email_schema.py`

- **定义数据结构**：使用 Pydantic 定义了一个强类型的数据模型 `EmailParams`。
- **作用**：这是给 LLM（大模型）看的“说明书”。当 Agent 决定要调用发邮件工具时，LLM 会根据这个 Schema 提取出收件人、主题和内容。如果提取格式不对，Pydantic 会自动报错，保证传入工具的参数是合法的。

```python
from pydantic import BaseModel,Field
# 定义工具参数校验类
class EmailParams(BaseModel):
    # 收件人
    to:str = Field(...,description="收件人邮箱")
    # 邮件主题
    subject:str = Field(...,description="邮件主题")
    # 邮件内容
    content:str = Field(...,description="邮件内容")
```

### 2. 发送邮件工具 -- `send_email_tool.py`

- **LangChain Tool 装饰器**：`@tool` 装饰器将一个普通的 Python 函数包装成 LangChain 可以识别的工具。`args_schema=EmailParams` 绑定了上一步定义的参数校验类。
- **业务逻辑**：标准的 SMTP 邮件发送流程。注意这里使用了 `smtplib.SMTP_SSL`，说明连接的是加密端口（通常是 465）。
- **返回值**：函数返回的字符串（成功或失败信息）会被传回给 LLM，让 LLM 知道任务执行的结果，从而决定下一步是告诉用户“发送成功”还是“重试”。

```python
from langchain.tools import tool
from email.mime.text import MIMEText    # 写邮件
import smtplib  # 发送邮件
from app.ai.tool.schema.send_email_schema import EmailParams
from dotenv import load_dotenv
import os
load_dotenv()

# 定义工具
@tool(
    "send_email_tool",  # 可选，默认用对应方法名作为工具名称
    description="发送邮件工具",
    args_schema=EmailParams,
)
def SendEmailTool(to:str,subject:str,content:str)->str:
    """用于发送邮件，发送通知，发送信息"""
    # 读取配置文件信息
    email = os.getenv("SENDER_EMAIL")   # 发件人邮箱
    host = os.getenv("EMAIL_HOST")
    port = os.getenv("EMAIL_PORT")
    password = os.getenv("SENDER_EMAIL_PASSWORD")
    # 判断配置是否读取成功
    if not email or not host or not port or not password:
        raise Exception("配置文件信息读取失败")
    
    # 每个工具都要加异常处理
    try:
        # 1. 构建邮件对象
        msg = MIMEText(content)
        msg['To'] = to  # 收件人
        msg['Subject'] = subject    # 邮件主题
        msg['From'] = email  # 发件人
        
        # 2. 连接 SMTP 服务器并发送
        # port读取出来为字符串，需要转换为int
        with smtplib.SMTP_SSL(host,int(port)) as smtp:  
            # 登录邮件服务器
            smtp.login(email,password)
            # 发送邮件
            smtp.sendmail(email,to,msg.as_string())
        return "发送邮件成功\n"
    except Exception as e:
        print(f"【测试】发送邮件失败:{e}")
        return f"发送邮件失败:{e}"
```

```python
    # 获取是否继续出题
    continue_question = state.get("continue_question",True)

    # 如果是第一次进入

    elif exam_state == "evaluate":

    elif exam_state == "done":  # 评价结束
```

```html
            <!-- ==================== 右侧：对话区 ==================== -->

                <!-- 消息区 -->

    <script>
        new Vue({
            el: "#app",   // 绑定html元素

            data: {       // 定义数据和变量
                chatList: [],       // 聊天内容
                input: "",          // 输入内容
                userId: "",         // 用户id
                searchKey: "",      // 搜索关键词
                sessions: [],       // 历史会话 [{id,title,ts,list}]
                currentId: null,    // 当前会话 id
                isRecording: false, // 是否正在语音输入

                // 多智能体展示（低饱和淡色背景）
                agents: [
                    { name: "技术面试官", icon: "💻", desc: "深挖项目与八股", bg: "#f6f8fe" },
                    { name: "HR 面试官", icon: "🤝", desc: "软技能与稳定性", bg: "#fdf7fa" },
                    { name: "压力面官", icon: "🔥", desc: "临场抗压与追问", bg: "#fdfaf4" }
                ],

                // AI 提示词
                prompts: [
                    "请做一段自我介绍",
                    "问我 3 个高频面试题",
                    "帮我分析简历里的项目亮点",
                    "模拟一场压力面试",
                    "我上一个回答有哪些不足？"
                ]
            },

            computed: {
                // 模糊搜索过滤历史记录
                filteredSessions() {
                    const k = this.searchKey.trim().toLowerCase();
                    if (!k) return this.sessions;
                    return this.sessions.filter(s =>
                        (s.title || "").toLowerCase().indexOf(k) > -1
                    );
                },
                // 当前对话标题
                currentTitle() {
                    const s = this.sessions.find(x => x.id === this.currentId);
                    return s ? s.title : "新的模拟面试";
                },
                // 头像文字
                avatarText() {
                    const n = (this.userId || "访客").replace(/[^0-9a-zA-Z\u4e00-\u9fa5]/g, "");
                    return (n.slice(0, 1) || "访").toUpperCase();
                }
            },

            mounted() {
                // 用户身份（保持在后端 user_id 参数中使用）
                let uid = localStorage.getItem("mi_user_id");
                if (!uid) {
                    uid = "user_" + Math.random().toString(36).slice(2, 7);
                    localStorage.setItem("mi_user_id", uid);
                }
                this.userId = uid;

                // 恢复历史记录
                try {
                    const raw = localStorage.getItem("mi_sessions");
                    if (raw) this.sessions = JSON.parse(raw) || [];
                } catch (e) {
                    this.sessions = [];
                }

                this.$nextTick(this.autoResize);
            },

            methods: {    // 函数

                /* ================= 发送消息（保留原有流式逻辑） ================= */
                send() {
                    const question = this.input.trim();

                    // 问题不能为空
                    if (question === "") {
                        return;
                    }

                    // 添加用户信息
                    this.chatList.push({
                        type: "user",
                        content: question,
                        time: new Date()
                    });

                    // 创建空AI消息，用于流式追加
                    const aiMsg = {
                        type: "ai",
                        role: "ai",
                        content: "正在思考，请稍等....",
                        time: new Date()
                    };
                    this.chatList.push(aiMsg);

                    // 清空输入框并自适应高度
                    this.input = "";
                    this.$nextTick(() => {
                        this.autoResize();
                        this.scrollToBottom();
                    });

                    // 保存到历史记录
                    this.saveCurrent();

                    // 定义参数格式
                    const params = `question=${encodeURIComponent(question)}&user_id=${encodeURIComponent(this.userId)}`;

                    // 创建流式对象
                    const eve = new EventSource("/chat?" + params);

                    let finished = false;

                    // 监听事件
                    eve.onmessage = (e) => {
                        // 打印流式输出
                        console.log(e.data);

                        // 把字符串格式的字典转换成json
                        let data;
                        try {
                            data = JSON.parse(e.data);
                        } catch (err) {
                            console.error("[SSE Parse Error]", err, "Raw:", e.data);
                            return;
                        }

                        // 是否关闭流式
                        if (data.done) {
                            finished = true;
                            // 关闭流式
                            eve.close();

                            if (aiMsg.content.indexOf("正在思考") > -1) {
                                aiMsg.content = "本次没有返回内容，请再试一次～";
                            }
                            this.saveCurrent();
                            this.scrollToBottom();
                        } else {
                            // 相当于 "正在思考" in aiMsg.content
                            if (aiMsg.content.indexOf("正在思考") > -1) {
                                aiMsg.content = "";
                            }
                            // 追加AI消息
                            aiMsg.content += data.data;
                            this.scrollToBottom();
                        }
                    };

                    // 异常处理
                    eve.onerror = () => {
                        if (finished) return;
                        if (aiMsg.content.indexOf("正在思考") > -1) {
                            aiMsg.content = "😥 连接中断了，请检查网络后重新发送～";
                        }
                        try { eve.close(); } catch (err) { }
                        this.saveCurrent();
                    };
                },

                /* ================= 历史会话管理 ================= */
                saveCurrent() {
                    if (this.chatList.length === 0) return;

                    const firstUser = this.chatList.find(m => m.type === "user");
                    const title = firstUser
                        ? firstUser.content.slice(0, 18) + (firstUser.content.length > 18 ? "…" : "")
                        : "新的模拟面试";

                    if (this.currentId) {
                        const s = this.sessions.find(x => x.id === this.currentId);
                        if (s) {
                            s.title = title;
                            s.ts = Date.now();
                            s.list = this.chatList.slice();
                        }
                    } else {
                        const s = {
                            id: "s_" + Date.now().toString(36) + Math.random().toString(36).slice(2, 5),
                            title: title,
                            ts: Date.now(),
                            list: this.chatList.slice()
                        };
                        this.sessions.unshift(s);
                        this.currentId = s.id;
                    }
                    this.persist();
                },

                persist() {
                    try {
                        localStorage.setItem("mi_sessions", JSON.stringify(this.sessions.slice(0, 30)));
                    } catch (e) { /* 忽略存储异常 */ }
                },

                newChat() {
                    this.saveCurrent();
                    this.currentId = null;
                    this.chatList = [];
                    this.input = "";
                    this.$nextTick(() => {
                        this.autoResize();
                        if (this.$refs.ta) this.$refs.ta.focus();
                    });
                },

                loadSession(item) {
                    this.currentId = item.id;
                    this.chatList = item.list || [];
                    this.$nextTick(this.scrollToBottom);
                },

                deleteSession(item) {
                    const i = this.sessions.findIndex(x => x.id === item.id);
                    if (i > -1) this.sessions.splice(i, 1);
                    if (this.currentId === item.id) {
                        this.currentId = null;
                        this.chatList = [];
                    }
                    this.persist();
                },

                logout() {
                    if (!confirm("确定要退出登录吗？退出后将清空本地会话记录。")) return;
                    localStorage.removeItem("mi_user_id");
                    localStorage.removeItem("mi_sessions");
                    this.sessions = [];
                    this.chatList = [];
                    this.currentId = null;

                    const uid = "user_" + Math.random().toString(36).slice(2, 7);
                    localStorage.setItem("mi_user_id", uid);
                    this.userId = uid;
                },

                /* ================= 交互辅助 ================= */
                usePrompt(p) {
                    this.input = p;
                    this.$nextTick(() => {
                        this.autoResize();
                        if (this.$refs.ta) this.$refs.ta.focus();
                    });
                },

                autoResize() {
                    const ta = this.$refs.ta;
                    if (!ta) return;
                    ta.style.height = "auto";
                    ta.style.height = Math.min(ta.scrollHeight, 140) + "px";
                },

                scrollToBottom() {
                    this.$nextTick(() => {
                        const el = this.$refs.chatBody;
                        if (el) el.scrollTop = el.scrollHeight;
                    });
                },

                /* ================= 语音输入 ================= */
                toggleVoice() {
                    const SR = window.SpeechRecognition || window.webkitSpeechRecognition;
                    if (!SR) {
                        alert("当前浏览器不支持语音输入，推荐使用 Chrome 浏览器～");
                        return;
                    }

                    if (this.isRecording) {
                        if (this._rec) this._rec.stop();
                        this.isRecording = false;
                        return;
                    }

                    const rec = new SR();
                    rec.lang = "zh-CN";
                    rec.continuous = false;
                    rec.interimResults = true;

                    rec.onresult = (e) => {
                        let text = "";
                        for (let i = 0; i < e.results.length; i++) {
                            text += e.results[i][0].transcript;
                        }
                        this.input = text;
                        this.$nextTick(this.autoResize);
                    };
                    rec.onend = () => { this.isRecording = false; };
                    rec.onerror = () => { this.isRecording = false; };

                    this._rec = rec;
                    this.isRecording = true;
                    try {
                        rec.start();
                    } catch (err) {
                        this.isRecording = false;
                    }
                },

                /* ================= 展示格式化 ================= */
                isThinking(msg) {
                    return msg.type !== "user"
                        && typeof msg.content === "string"
                        && msg.content.indexOf("正在思考") > -1;
                },

                renderMd(text) {
                    if (!text) return "";
                    try {
                        return marked.parse(text, { breaks: true, gfm: true });
                    } catch (e) {
                        return String(text).replace(/</g, "&lt;");
                    }
                },

                clock(t) {
                    const d = t instanceof Date ? t : new Date(t);
                    if (isNaN(d.getTime())) return "";
                    const pad = n => String(n).padStart(2, "0");
                    return pad(d.getHours()) + ":" + pad(d.getMinutes());
                },

                formatTime(ts) {
                    const d = ts instanceof Date ? ts : new Date(ts);
                    if (isNaN(d.getTime())) return "";
                    const pad = n => String(n).padStart(2, "0");
                    const hm = pad(d.getHours()) + ":" + pad(d.getMinutes());
                    const now = new Date();
                    const sameDay = (a, b) => a.toDateString() === b.toDateString();
                    if (sameDay(d, now)) return "今天 " + hm;
                    const yest = new Date(now.getTime() - 86400000);
                    if (sameDay(d, yest)) return "昨天 " + hm;
                    return (d.getMonth() + 1) + "月" + d.getDate() + "日 " + hm;
                }
            }
        });
    </script>
```
